# 📊 Olist E-Commerce Data Cleaning & Sales Analysis

A data analytics project focused on cleaning, organizing, and analyzing Olist e-commerce sales data to generate meaningful business insights and support data-driven decision-making.

## 📌 Project Overview

This project explores the Olist e-commerce dataset to understand sales performance and business trends. It involves working with cleaned sales data, visualizing important metrics, and presenting findings through an Excel dashboard and a business insights report.

The main objective is to transform raw data into meaningful information that can help understand business performance and identify useful patterns.

## 🎯 Project Objectives

- Clean and prepare sales data for analysis.
- Improve data quality and consistency.
- Analyze e-commerce sales performance.
- Identify trends and patterns in business data.
- Create visualizations to communicate findings.
- Present actionable business insights through reports and dashboards.

## 🛠️ Tools & Technologies

- **Microsoft Excel** – Data analysis and dashboard creation.
- **CSV** – Storage of cleaned sales data.
- **Data Visualization** – Charts and graphical representation of insights.
- **GitHub** – Project version control and documentation.

## 📈 Project Workflow

1. **Data Preparation:** Work with the Olist e-commerce sales dataset.
2. **Data Cleaning:** Organize and prepare the data for analysis.
3. **Data Analysis:** Explore sales data to identify trends and patterns.
4. **Data Visualization:** Create charts to represent important findings.
5. **Dashboard Creation:** Develop an Excel dashboard to present the analysis.
6. **Business Insights:** Document findings in a business insights report.
